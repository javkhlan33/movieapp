# 🎬 Movie App

A modern and responsive movie discovery web application built with Next.js and TypeScript.

🔗 **Live Demo:** https://movieapp-tau-seven.vercel.app

## ✨ Features

- 🎬 Browse movies
- 🔍 Search for movies
- 📄 View movie details
- 📱 Responsive design
- ⚡ Fast and modern UI
- 🌐 API integration

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- REST API
- Vercel
